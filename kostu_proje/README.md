# KOSTÜ Öğrenci Kulüpleri ve Etkinlik Yönetim Sistemi

Bu proje, üniversite öğrencileri için kulüp yönetimi ve etkinlik organizasyonunu kolaylaştırmak amacıyla hazırlanmıştır. Sistem, kulüp yöneticilerinin etkinlikleri yönetmesini, öğrencilerin kulüplere erişimini ve rol bazlı yetkilendirmeyi destekler.

## Amaç

KOSTÜ, öğrenci kulüpleri ve etkinlik süreçlerini daha düzenli, güvenli ve yönetilebilir hale getirmek için tasarlanmış bir web uygulamasıdır. Projede temel hedef, kulüp yönetimini kolaylaştırmak ve kullanıcı rollerine göre erişim kontrolü sunmaktır.

## Kullanılan Teknolojiler

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap

## Proje Yapısı

- `database/schema.sql` → Veritabanı yapısını oluşturan SQL dosyası
- `includes/config.php` → Veritabanı bağlantısı ve PDO ayarları
- `public/index.php` → Ana giriş sayfası
- `admin/login.php` → Yönetici giriş formu
